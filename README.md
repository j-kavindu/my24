## Installation

1. Open the [v1.0.0 release](https://github.com/j-kavindu/my24/releases/tag/v1.0.0).
2. Download **My24-v1.0.0.apk** from Assets.
3. Open the downloaded file on your Android device.
4. If Android requests it, temporarily allow **Install unknown apps** for the browser or file manager you used. Wording varies by device.
5. Review the installation prompt and install My 24.
6. Disable that installation permission afterward if you no longer need it.

This app is distributed outside Google Play. Install only from the official release linked above. Keep Android security protections enabled; if Android or Play Protect blocks installation, review the warning before proceeding.
