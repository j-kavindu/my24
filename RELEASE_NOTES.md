# My 24 v1.0.0

Initial public release of **My 24**, a native Android productivity and daily planning app built with Kotlin and Jetpack Compose.

## Included in this release

- Developer-supplied signed release APK, distributed directly through GitHub.
- Google AdMob banner and rewarded ads.
- Analytics access through a rewarded ad.

## Installation and requirements

Download **My24-v1.0.0.apk** below. Android 7.0 (API 24) or later is required; the developer reports target SDK 36 and package ID `com.kavindu.my24`. App version is 1.0; GitHub release tag is `v1.0.0`.

Follow the repository README for direct APK installation, security guidance, and privacy and advertising disclosures. This is a direct-download release outside Google Play. Source code is not included.

The developer reports that the APK has been tested. The supplied binary has not been rebuilt, re-signed, or modified; only its filename has been renamed.
